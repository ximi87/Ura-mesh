Join with your own point

  1. Set up a ura-mesh-client next to your repeater, with a Meshtastic and/or MeshCore radio.
  2. On its Admin page, under Server connection, enter this server's address and click Request to join.
  3. The server owner approves your point. Then add the Global channel on your radio (Meshtastic: a secondary channel, MeshCore: a new channel) and link it on the Admin page.
